# Evidencia 10

## Define una política de entre 5 y 10 reglas para la gestión de claves criptográficas
## Política para la gestión de claves criptográficas

1. **Generación:** Las claves deben generarse mediante herramientas criptográficas seguras.

2. **Almacenamiento:** Las claves no deben guardarse en archivos SQL, código fuente ni repositorios Git.

3. **Acceso:** Solo el personal autorizado puede acceder a las claves.

4. **Rotación:** Las claves deben cambiarse periódicamente y cuando exista sospecha de exposición.

5. **Respaldo:** Las claves deben tener copias de seguridad cifradas y protegidas.

6. **Revocación:** Las claves comprometidas deben revocarse o sustituirse inmediatamente.

7. **Exposición accidental:** Si una clave se publica por error, se debe retirar, reemplazar y revisar si la información fue comprometida.

8. **Eliminación:** Las claves que ya no se utilicen deben eliminarse de forma segura.

9. **Registro:** Se deben registrar los accesos y cambios realizados a las claves para detectar actividades sospechosas.
